## ✨ Features

* 🎨 Professional cyberpunk-inspired user interface
* 🖱️ Interactive cursor spotlight and glow effects
* ✨ Smooth scrolling and fade-in animations
* 👨‍💻 Skills, education and experience sections
* 🚀 Dedicated GitHub projects showcase
* 📱 Fully responsive desktop, tablet and mobile design
* 📄 Resume view and download options
* 📧 Contact section with clickable email and social links
* ⚡ Fast and lightweight static website
* ▲ Deployed on Vercel

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 and JavaScript
* **Design:** Responsive layouts, CSS Grid and Flexbox
* **Animations:** CSS animations and Vanilla JavaScript
* **Version Control:** Git and GitHub
* **Deployment:** Vercel

## 🔧 Run Locally

1. Clone the GitHub repository:

```bash
git clone https://github.com/ainulhaqsde/Cyber-Portfolio-Ainul-.git
```

2. Open the project directory:

```bash
cd Cyber-Portfolio-Ainul-
```

3. Open the folder in VS Code:

```bash
code .
```

4. Open `index.html` directly in your browser or use the **Live Server** extension in VS Code.
